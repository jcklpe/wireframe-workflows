# Example content
Wireframes need believable content to be judged, and made-up content must never be mistaken for real records.

- **Make it realistic.** Use names, addresses, numbers and copy of realistic shape and length, so layouts are tested by what they will actually hold.
- **Include awkward cases.** Long names, missing values, zero results, very large numbers and error messages belong alongside the typical case.
- **Label it.** Mark made-up content as such on the board or in its notes, so screenshots and exports cannot be read as facts.
- **Never use real personal records.** Do not copy real people's or organizations' data into wireframes unless the user confirms it is public and appropriate.
- **Keep it consistent.** Use the same example data across options and states being compared, so only the design differs.
